## 关键取舍

LangGraph 被封装在工作流深模块中，Application、FastAPI 和前端不认识 Graph State。首个网页 Provider 选择无需密钥的 Stack Exchange API；它适合当前 AI 编程技术问题，但不代表通用 Web 搜索。Wikipedia 方案曾在当前运行网络遭遇 robots 403，因此没有作为 M2 生产适配器保留。

## 已知限制与后续

- 来源只覆盖 Stack Overflow，学术论文和工业产品文档留到 M3；
- 当前检查只验证 Evidence—Source 关联和至少一个报告链接，不是 Claim 级引用验证；
- 没有 LangGraph 持久 checkpoint；异常中断按 `RUN_INTERRUPTED` 结束，恢复与重试属于 M5；
- SQLite 仍使用启动时建表，公开部署前需要正式迁移方案；
- 在线 Demo 的鉴权、限流、持久磁盘、备份和费用上限仍按 M5 部署指南推进。
