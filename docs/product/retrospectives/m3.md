## 关键取舍

`Claim` 表示报告需要陈述的关键结论，`Evidence` 表示支持它的材料片段，`Citation Coverage` 表示具有有效证据关联的主张比例。三者分别承担语义、支撑材料和质量度量，避免把一段搜索摘要同时当作结论和引用。

来源分类采用保守、确定性的 URL 规则。无法可靠判断的来源保留为 `other`，不让 LLM 猜测类型。元数据使用独立表补充既有 Source，保证已有 SQLite 数据库无需破坏性重建。可追溯章节由工作流根据已持久化关系生成，避免仅依赖模型自觉输出格式正确的引用。

Exa 固定查询已满足黄金场景的当前覆盖门槛，因此不增加专用学术 Provider。现有 `SearchProvider` 接口仍允许未来替换或组合更高质量的付费服务。

## 已知限制与后续

- 来源类型是启发式分类，不等同于人工审校；新增重要域名时需要补充规则和测试；
- 公开网页经常缺少作者或发布日期，系统只保存 Provider 能可靠返回的字段；
- 当前不归一化 DOI、期刊、会议和被引量，只有明确需求和评测收益时再增加专业元数据服务；
- 引用检查验证关系和报告呈现，不自动判断证据是否在语义上充分支持主张；更深入的一致性评测属于后续质量增强；
- M4 应让本地文档复用统一 Evidence 模型，并为文件名、页码或片段位置保留可定位信息。
