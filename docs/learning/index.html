ResearchFlow Learning

从零读懂一个 AI 深度研究项目

从浏览器的一次点击开始，逐步理解 FastAPI、SQLite、异步任务、LangGraph、搜索、RAG、证据链、测试和部署，最后用资深面试官视角深挖项目取舍与生产边界。

怎样使用这套课程

推荐方法：先读简要结论，再看详细解析；每课至少打开一次链接的真实代码。架构文档回答“项目规定是什么”，课程回答“为什么这样设计、面试时怎样解释”。
  1. 完全初学者按五个阶段顺序阅读，不要求一次记住所有名词。
  2. 已经熟悉某一层时，可以直接进入专题课，但先看第 0 课和第 2 课建立全局路径。
  3. 标为“当前未实现”的技术用于理解取舍，不代表项目已经拥有该能力。
  4. 完成基础课后进入“面试深挖”阶段，文中会直接给出完整回答、源码证据、适用边界和演进方向。
