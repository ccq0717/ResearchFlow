创建任务的主路径

page.tsx 表单
  → lib/api.ts 发送 POST
  → api/routes.py 接收
  → ResearchRunApplication.create_run()
  → SqliteResearchRepository.create()
  → var/researchflow.db
  → HTTP 201 + run.id 返回前端

真实研究材料与实时进度的主路径

LangGraphResearchWorkflow → LLMClient + Web adapters
  → research_plans + research_tasks + research_sources + research_evidence
  → 前端读取 /plan 与 /materials 并展示

任一 ResearchWorkflow
  → Application 持久化 ResearchWorkflowUpdate 到 research_events
  → FastAPI StreamingResponse
  → 浏览器 EventSource
  → React 状态更新
  → 进度条和研究事件重绘
定位原则：页面样式先看组件；请求失败先看 Network 和路由；状态错误看应用层与工作流；刷新后数据错误看 Repository 和 SQLite；实时更新错误看事件表与 SSE。
