# Mission: 通过 ResearchFlow 掌握 AI 全栈开发

## Why

通过亲手理解和迭代一个能演示的 AI 深度研究产品，建立前端、后端与 AI 应用工程的完整知识框架，从而能够求职 AI 全栈工程师，并在面试中解释关键设计和代码。

## Success looks like

- 能从浏览器操作出发，说明一次请求如何经过前端、后端、数据库和 Agent 工作流
- 能阅读并修改 ResearchFlow 的 Next.js、FastAPI 和 SQLAlchemy 代码
- 能解释 SSE、REST、异步任务、RAG、工作流状态和引用验证等核心概念
- 能独立运行、调试、测试并演示项目
- 能结合代码和技术取舍向面试官讲清项目，而不是只会复述文档

## Constraints

- 当前只有基础计算机和编程知识，按前后端零基础设计课程
- 使用中文讲解，代码标识符和行业通用术语保留英文
- 课程必须联系 ResearchFlow 的真实代码和演示场景
- 主要在 Windows 上学习和运行，尽量控制本地资源占用
- 每节课聚焦一个小主题，直接解释关键结论，不设置课末练习或实践任务

## Out of scope

- 暂不系统学习浏览器内核、网络协议栈和分布式系统理论
- 暂不追求复杂微服务、Kubernetes 或大规模生产集群
- 暂不为了覆盖知识点而加入与 ResearchFlow 无关的技术
