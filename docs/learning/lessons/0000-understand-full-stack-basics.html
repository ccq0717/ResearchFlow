从浏览器、网络到前后端：先建立完整地图

如果你只学过单机程序，这一课会从“网页为什么需要服务器”开始，解释 URL、端口、HTTP、JSON、React、Next.js、Python 和 FastAPI 在 ResearchFlow 中分别是什么。

简短回答：ResearchFlow 是一个 Web 应用。浏览器运行 TypeScript/React 前端，通过 HTTP 请求 Python/FastAPI 后端；后端保存数据、调用外部 AI 服务并执行研究流程。前端和后端是两个独立进程，即使它们都运行在你的电脑上，也要通过网络协议通信。

1. 从单机程序到 Web 应用

普通命令行程序往往在一个进程里读取输入、计算并打印结果。Web 应用把“与用户交互”和“执行业务”拆开：

用户
  ↓ 点击、输入
浏览器中的前端
  ↓ HTTP
服务器上的后端
  ↓
数据库与外部服务

这样做的好处是用户只需要浏览器，不需要直接操作 Python、数据库和密钥；后端也可以同时服务多个浏览器。即使本地开发时前后端都在一台电脑上，这个职责划分仍然存在。

2. Client 和 Server 是什么

Client（客户端）主动发起请求，Server（服务器）监听地址并响应请求。这描述的是一次通信中的角色，不一定代表两台物理机器。

  • 浏览器请求 ResearchFlow API 时，浏览器是客户端，FastAPI 是服务器；
  • FastAPI 请求 Exa 或 LLM 时，FastAPI 又成为客户端，外部平台是服务器；
  • “后端”是应用职责，“服务器”是通信角色，两者经常重合但不是同义词。

3. 进程、主机和端口

进程是正在运行的程序实例。ResearchFlow 本地开发通常至少有两个进程：Next.js 前端和 FastAPI 后端。操作系统用端口把到达同一台主机的网络流量交给正确进程。

地址部分例子含义
协议 Schemehttp通信规则；线上通常是加密的 HTTPS
主机 Host127.0.0.1本机回环地址，只指向当前设备
端口 Port3000接收请求的具体进程入口
路径 Path/research/abc该服务器中的页面或资源

http://127.0.0.1:3000 和 http://127.0.0.1:8000 是同一台电脑上的两个不同 Origin。前者通常是前端，后者是后端 API。端口不是目录，也不是某种编程语言。

4. localhost、127.0.0.1 和线上域名

localhost 是通常解析到本机回环地址的主机名，127.0.0.1 是 IPv4 回环地址。别人电脑上的 localhost 指向他自己的电脑，因此不能把本地链接直接发给面试官远程访问。

线上部署后，域名通过 DNS 解析到公网服务，HTTPS 负责加密传输并验证服务身份。应用代码可以跨 Windows 和 Linux 运行；地址、进程启动方式和存储挂载由部署环境决定。

5. URL、路由和页面不是一回事

URL（Uniform Resource Locator，统一资源定位符）描述资源的位置。路由规则决定某个路径由哪段代码处理：

  • / 由 Next.js 首页组件渲染；
  • /research/{runId} 由动态研究页面渲染；
  • /api/research-runs 由 FastAPI 返回 JSON，不是给人直接阅读的网页。

页面路由和 API 路由都使用 URL，但返回内容和服务对象不同。

6. HTTP 是什么

HTTP 的全称是 Hypertext Transfer Protocol，中文是“超文本传输协议”。它规定客户端怎样描述请求、服务器怎样返回响应。HTTP 不只传 HTML，也能传 JSON、图片、PDF 和 SSE 事件流。

请求 Request
POST /api/research-runs HTTP/1.1
Content-Type: application/json

{"goal":"调研 AI 代码生成评测方法","document_ids":[]}

响应 Response
HTTP/1.1 201 Created
Content-Type: application/json

{"id":"...","status":"queued", ...}

7. HTTP 请求由什么组成

  • Method：想做什么，例如 GET 读取、POST 创建、PATCH 修改、DELETE 删除；
  • Path：操作哪个资源；
  • Header：内容类型、认证、缓存等元信息；
  • Body：可选正文，例如创建研究时的 JSON；
  • Query Parameter：路径后的筛选或位置参数，例如 ?after=12。

HTTP 方法表达意图，但服务器代码仍决定真实行为。仅仅把一个删除操作写成 GET 不会让它安全，合理接口还要遵守语义和权限边界。

8. 状态码怎么读

范围含义项目示例
2xx请求成功处理200 读取成功，201 创建成功，204 删除成功且无正文
4xx请求或客户端状态有问题401 未解锁 Demo，404 运行不存在，422 输入校验失败
5xx服务器未能完成请求未预期异常或上游服务故障映射

状态码是机器可读的粗分类；ResearchFlow 的错误正文还包含稳定错误码和用户可读消息，以便前端给出更具体反馈。

9. JSON 是什么

JSON 全称是 JavaScript Object Notation，中文常称“JavaScript 对象表示法”。它是一种语言无关的文本数据格式。浏览器把 TypeScript 对象序列化成 JSON 文本，Python 后端再解析成自己的对象。

{
  "goal": "调研 RAG 评测方法",
  "document_ids": [],
  "archived": false
}

JSON 支持对象、数组、字符串、数字、布尔值和 null，不支持 Python 的 tuple、datetime 或自定义类。跨网络前必须转换成双方约定的字段。

10. API 和 REST 是什么

API 是 Application Programming Interface，中文是“应用程序编程接口”。它是软件之间约定好的调用边界。Web API 通常用 HTTP 暴露能力。

REST 是一种围绕资源组织 HTTP 接口的架构风格。ResearchFlow 用 /research-runs 表示研究运行集合，用 /research-runs/{id} 表示某一项，再用不同 HTTP 方法表达动作。REST 不是框架，也不是“所有返回 JSON 的接口”。

11. 前端、后端和全栈分别是什么

部分关注点当前技术
Frontend 前端用户看到什么、怎样交互、页面状态如何变化TypeScript、React、Next.js
Backend 后端业务规则、数据、权限、长任务和外部服务Python、FastAPI、LangGraph、SQLite
Full Stack 全栈理解并连接以上两端及其部署不是一门单独语言

“全栈”不表示一个人精通所有底层细节，而是能理解一项功能怎样跨越页面、协议、后端和数据层。

12. JavaScript 和 TypeScript 的关系

JavaScript 是浏览器原生执行的编程语言。TypeScript 在 JavaScript 上增加静态类型检查，开发时更容易发现字段和函数调用错误。浏览器最终执行构建工具生成的 JavaScript，而不是直接理解所有 TypeScript 类型。

type ResearchRun = {
  id: string;
  status: "queued" | "running" | "completed" | "failed";
};

类型能帮助开发者，却不能验证不可信网络响应。真正运行时的数据仍要由 API 契约和必要校验保证。

13. React 是什么

React 是构建用户界面的 JavaScript 库。它把页面拆成组件，并根据数据状态声明页面应该长什么样。当 state 改变时，React 重新计算需要更新的界面。

概念初学者理解项目示例
Component可复用的界面函数研究报告、材料面板、错误面板
Props父组件传给子组件的输入把 reportMarkdown 交给报告组件
State组件记住且会影响显示的数据运行、事件、连接状态、弹窗
Effect组件与网络等外部系统同步读取 REST、建立并关闭 SSE

React 不直接操作数据库，也不负责调用 LLM。它通过后端 API 获得可以展示的数据。

14. Next.js 和 React 的关系

React 主要解决组件和界面更新；Next.js 是建立在 React 上的 Web 框架，提供目录路由、开发服务器、生产构建和服务端/客户端组件边界。

  • app/page.tsx 对应首页；
  • app/research/[runId]/page.tsx 中方括号表示动态路径参数；
  • "use client" 表示组件需要浏览器事件、state 或 Effect；
  • 构建阶段会检查类型、打包资源并优化生产输出。

只写 TypeScript 不能自动获得页面路由和 React 渲染；Next.js 因此值得在技术栈中单独列出。

15. Python、FastAPI 和 Pydantic 的关系

Python 是后端编程语言；FastAPI 是用 Python 构建 Web API 的框架；Pydantic 根据类型声明解析和验证运行时数据。

@router.post("/research-runs", status_code=201)
async def create_research_run(
    body: CreateResearchRunRequest,
    request: Request,
):
    return await application.create_run(body.goal, body.document_ids)

FastAPI 根据装饰器注册路径，读取 HTTP 请求，把 JSON 交给 Pydantic Schema 验证，再调用 Python 函数。函数把业务交给 Application，而不是在路由里直接写 SQL 或拼 Prompt。

16. 为什么浏览器不能直接调用数据库和 AI 服务

  • 浏览器代码会下载到用户设备，放在里面的 API Key 会泄露；
  • 让用户直接写数据库很难统一执行权限和业务约束；
  • 不同模型和搜索服务的请求格式会污染前端；
  • 后台任务在页面关闭后仍需继续，不能绑定浏览器生命周期；
  • 后端是集中实施配额、日志、错误映射和持久化的边界。

18. 一次创建请求的完整方向

点击按钮→TypeScript 调 API→FastAPI 校验→Application 创建→SQLite 保存

后端返回运行 ID 后，浏览器跳转到研究页；研究页用 REST 读取当前快照，再用 SSE 接收后续进度。整个项目后面的知识都可以放回这条主线中理解。

19. 初学者最常混淆的说法

  • “打开前端就等于后端启动了”：不是，两个开发服务器是独立进程。
  • “localhost 是一个公共网站”：不是，它只指当前设备。
  • “React 是编程语言”：React 是 JavaScript/TypeScript 生态中的界面库。
  • “Next.js 可以被 TypeScript 完全涵盖”：语言描述语法，框架还提供路由、构建和运行模型。
  • “FastAPI 就是 Python”：Python 是语言，FastAPI 是其中的 Web 框架。
  • “API 成功就是业务成功”：创建返回 201 只表示运行已入队，最终研究仍可能失败。

20. DNS、TCP 和 HTTP 是什么关系

访问线上域名时，DNS（Domain Name System，域名系统）先把域名解析为 IP 地址；浏览器再与目标建立传输连接，HTTP 在连接上传递请求和响应。本地 localhost通常不需要公网 DNS。传统 HTTP/1.1 和 HTTP/2 常运行在 TCP 上，HTTP/3 则基于 QUIC/UDP；应用代码通常通过浏览器和服务器框架使用这些能力，不需要自己编写网络包。

21. HTTPS 比 HTTP 多了什么

HTTPS 是运行在 TLS（Transport Layer Security，传输层安全协议）之上的 HTTP。TLS 通过证书帮助浏览器验证服务器身份，并为传输提供加密与完整性保护。它保护“传输途中”，不能阻止服务器自身泄露数据，也不能替代登录、授权和输入校验。本地开发可用 HTTP，公开部署必须使用 HTTPS。

22. 浏览器拿到 HTML 后怎样出现可交互页面

  1. 解析 HTML，构建 DOM（Document Object Model，文档对象模型）。
  2. 解析 CSS，计算每个元素的样式和布局。
  3. 下载并执行 JavaScript；React 将组件状态与 DOM 更新关联起来。
  4. Next.js 返回的初始内容与浏览器组件连接，称为 Hydration（水合）。
  5. 点击事件触发状态变化或 API 请求，React 再渲染受影响部分。

“页面由 Next.js 生成”和“交互在浏览器运行”可以同时成立。具体取决于组件是 Server Component 还是 Client Component。

23. 为什么前后端要约定数据契约

TypeScript 接口只在前端编译期工作，Python 类型只在后端代码侧工作；它们不会自动跨网络同步。真正的边界是 HTTP 方法、路径、状态码和 JSON 字段。后端 Pydantic 负责运行时校验，前端类型帮助开发时发现错误。若接口字段变化，应同步 Schema、前端类型和契约测试，否则任一侧都可能“单独编译通过、联调失败”。

24. 前后端分离的收益和成本

收益是界面与业务可以独立组织，后端 API 也能被其他客户端复用；成本是多一个部署单元、跨域配置、网络错误和数据同步问题。ResearchFlow 需要长任务、SSE、上传与丰富研究页面，分离较自然。小型静态站若没有复杂后端，没必要照搬这种结构。

面试表达：ResearchFlow 是前后端分离的 Web 应用。Next.js/React 前端在浏览器运行，通过 HTTP/JSON 调用 FastAPI；后端掌握业务、密钥、持久化和长任务。创建接口快速返回运行 ID，研究页再通过 REST 快照与 SSE 增量展示执行过程。线上链路还包含 DNS、传输连接和 TLS，前后端真正共享的是 API 契约而不是语言类型。
