ResearchFlow Learning · Sources

课程资料依据

课程用项目代码说明“ResearchFlow 现在怎样做”，用下面的规范、官方文档和论文核对通用概念。安装与配置仍以项目正式文档为准。

前端、HTTP 与实时通信

  • Next.js App Router：路由、布局、页面和组件体系。
  • Server and Client Components：服务端与浏览器组件的职责。
  • React Learn：组件、状态、事件和副作用。
  • HTTP Overview — MDN：请求、响应和 HTTP API 基础。
  • Server-sent events — WHATWG：SSE 标准行为与事件格式。
  • Using server-sent events — MDN：浏览器连接、监听、关闭与重连。
  • Server-Sent Events — FastAPI：Python 后端流式返回事件。
  • react-markdown：Markdown 到 React 元素的安全渲染。
  • remark-math 与 rehype-katex、KaTeX：数学语法解析和公式渲染。

Python、API 与数据持久化

  • Coroutines and Tasks — Python：协程、Task、取消和 shield。
  • typing — Python：Protocol、类型提示和结构化子类型。
  • FastAPI Tutorial：路由、请求模型、依赖和错误处理。
  • SQLite Is Serverless：嵌入式、无独立服务器进程的数据库模式。
  • sqlite3 — Python：Python 访问本地 SQLite 文件。
  • Asynchronous I/O — SQLAlchemy：异步 Engine、Connection 和 Session。
  • aiosqlite：sqlite3 与 asyncio 之间的桥接。

LLM、工作流、搜索与 RAG

  • LangGraph overview：低层有状态编排框架的官方定位。
  • Persistence — LangGraph：Graph State、Checkpoint 和恢复能力；项目当前未启用 Checkpointer。
  • JSON Schema：结构化数据的字段、类型和约束定义。
  • Search API — Exa：通用网页搜索结果和内容选项。
  • Retrieval-Augmented Generation — NeurIPS 2020：RAG 的参数化与外部非参数记忆。
  • Gemini Embeddings、EmbedContent API：模型、检索用途与请求响应字段。
  • Introduction to Information Retrieval：余弦相似度、相关性和信息检索基础。
  • Evaluation in information retrieval：查询集、相关性标注与评测指标。
  • Text REtrieval Conference — NIST：语料、查询与 qrels 的可复现评测方法。

容器、Git、自动化与延伸交流

  • What is an image? — Docker：镜像的只读分层和构建来源。
  • What is a container? — Docker：容器、隔离进程和持久数据。
  • Building images — Docker：Dockerfile 与镜像构建流程。
  • What is Git? — Pro Git：工作区、暂存区和本地仓库。
  • Workflows — GitHub Actions：Trigger、Job、Step 和 Runner。
  • FastAPI Discussions 与 Next.js Discussions：遇到版本或框架边界问题时的社区讨论入口。
注意：框架 API、云服务限制和平台价格会变化。课程解释的是当前项目采用的能力和稳定基础概念；准备部署或升级依赖时，应重新核对相应官方文档。
